# Wrappee — LiveKit

This repo wraps **LiveKit** ([livekit.io](https://livekit.io)) as its real-time media host:
the open-source WebRTC SFU plus the Agents framework that powers our conferencing and the Visio
voice assistant. LiveKit is never bundled — install it separately ([ONBOARDING.md](ONBOARDING.md)).

**Full picture:** [LIVEKIT_OVERVIEW.md](LIVEKIT_OVERVIEW.md) (what it is, history, who uses it,
community, bibliography) → [LIVEKIT.md](LIVEKIT.md) (server config reference).
